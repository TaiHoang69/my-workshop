During my FCAJ internship program, I completed a 12-week worklog, starting from August 8, 2026. During this period, I gradually studied fundamental AWS concepts, practiced AWS services, deployed an application in the cloud environment, and learned how to build a CI/CD workflow.

The activities throughout the 12 weeks were organized as follows:

**Week 1:** [Getting familiar with AWS and basic AWS services](1.1-week1/)

**Week 2:** [Learning IAM, VPC, and networking fundamentals](1.2-week2/)

**Week 3:** [Learning and practicing Amazon EC2](1.3-week3/)

**Week 4:** [Learning Amazon S3 and CloudFront](1.4-week4/)

**Week 5:** [Learning Amazon RDS and database management](1.5-week5/)

**Week 6:** [Deploying the backend application on AWS](1.6-week6/)

**Week 7:** [Deploying the frontend and integrating the system](1.7-week7/)

**Week 8:** [Learning Docker and Amazon ECS](1.8-week8/)

**Week 9:** [Learning GitHub and building a CI/CD pipeline](1.9-week9/)

**Week 10:** [System integration and AWS security](1.10-week10/)

**Week 11:** [Learning CloudWatch and system monitoring](1.11-week11/)

**Week 12:** [Completing, testing, and reviewing the project.](1.12-week12/)
