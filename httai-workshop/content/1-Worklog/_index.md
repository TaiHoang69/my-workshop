Over 12 weeks, I focused on learning AWS services and working on the infrastructure deployment of a phone-selling web application. The work began with cloud fundamentals, networking, and access management. It then progressed to server, database, storage, and frontend delivery infrastructure, followed by system connectivity, monitoring, and testing.

The activities throughout the 12 weeks were organized as follows:

**Week 1:** [Getting started with AWS and planning the deployment architecture](1.1-week1/)

**Week 2:** [Learning and configuring AWS IAM](1.2-week2/)

**Week 3:** [Designing Amazon VPC and network access rules](1.3-week3/)

**Week 4:** [Preparing an Amazon EC2 application server](1.4-week4/)

**Week 5:** [Configuring Amazon RDS for MySQL](1.5-week5/)

**Week 6:** [Setting up Amazon S3 for frontend assets and images](1.6-week6/)

**Week 7:** [Delivering the frontend with Amazon CloudFront](1.7-week7/)

**Week 8:** [Deploying the Spring Boot application to EC2](1.8-week8/)

**Week 9:** [Integrating frontend, backend, and database connectivity](1.9-week9/)

**Week 10:** [Finalizing image storage and delivery configuration](1.10-week10/)

**Week 11:** [Monitoring the system with Amazon CloudWatch](1.11-week11/)

**Week 12:** [End-to-end testing and compiling workshop material](1.12-week12/)
